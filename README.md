# Robot Instagram perso (@jyn_mjl)

Publie mardi, jeudi et samedi vers 18 h 30 les posts du compte Meujesse Learning, dans un autre ordre
(au moins 4 semaines d'écart avec le même post chez Meujesse). Calendrier : `calendrier.json`, construit par
`outils/planifier.py` (dossier ~/Downloads/meujesse-instagram-perso). Page des liens en bio : https://meujesse.github.io/instagram-perso/
Les médias sont ceux du dépôt Meujesse/instagram. Jyn peut publier ses propres posts quand elle veut : le robot n'y touche pas.
